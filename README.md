# זיהוי פנים

תוכנת Windows מקומית (עברית) לזיהוי פנים, נוכחות, מיון תמונות וסריקת וידאו — עם ממשק בעיצוב אינטרנט ועוזר AI.

**הורדה:** ב-[Releases](https://github.com/JHGJHJCD/face-recognition/releases/latest) — קובץ `FaceID.exe` יחיד.
בהפעלה הראשונה התוכנה מורידה לבד את מודלי הזיהוי (~380MB) לתיקיית `models` לידה. עדכונים מגיעים אוטומטית מתוך התוכנה.

הזיהוי עצמו רץ במחשב בלבד. רכיב ה-AI (Gemini) — היחיד ששולח תמונות לענן — ניתן לכיבוי בהגדרות.
