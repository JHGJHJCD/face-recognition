# שפת העיצוב — "איריס" (20/9/2026)

יהודה ביקש: "שלא תיראה תוכנה שבינה מלאכותית יצרה אלא משהו מלוטש שמתכנת יצר — זרוק את הקודם לפח".
העיצוב הקודם ("משרד הרישום + עינית": נייר קרם, פרנק-ריהל 900, סימון צהוב, חותמות) היה תמה תחפושתית — בדיוק הסימן של עיצוב-AI. הוחלף כולו.

## הרעיון
כלי עבודה שקט ומדויק, כמו תוכנה שמתכנת מלטש לעצמו. אין מטאפורה — יש היררכיה, ריווח ופרטים קטנים. הדבר הבולט היחיד הוא תמונת המצלמה.

## חמש הזוויות של השדרוג
1. **צבע ומשטחים** — גרפיט ניטרלי בשלוש שכבות (`--side` / `--bg` / `--surface` / `--raised`). צבע פעולה אחד: סגול-כחול "קשתית" (`--accent`).
   ירוק/כתום/אדום/צהוב שמורים **רק** למצבי זיהוי (מוכר/לא-מוכר/זיוף/בבדיקה) ולהודעות. צל רק למה שצף (חלון, הודעה, חיפוש). יום/לילה מכוונים בנפרד.
2. **טיפוגרפיה** — גופן אחד: **Rubik משתנה** (`fonts/rubik-hebrew.woff2`, `rubik-latin.woff2`, OFL, מ-jsdelivr/fontsource). סולם: 12 / 12.5 / 13.5 / 14.5 / 16.5 / 19 / 26.
   משקלים 400/450/500/600 בלבד. מספרים תמיד `tabular-nums`. כותרת מסך 19px — לא כרזה.
3. **מבנה וניווט** — סרגל צד צר עם קבוצות (זיהוי / מעקב / מערכת), כותרת עליונה קומפקטית, **Ctrl+1…8** למסכים, **Ctrl+K** חיפוש מהיר (מסכים + אנשים).
4. **תנועה ומשוב** — רק תגובה לפעולה: מעבר מסך 160ms, חלון קופץ, הודעה, מתג קפיצי, שלד-טעינה, אישור "נרשם". התנועה היזומה היחידה: הלוגו מתמקד בפתיחה. `prefers-reduced-motion` מכובד.
5. **פרטים** — בלי אימוג'י (רק סמלי SVG בקו אחיד), מסכים ריקים עם סמל + כותרת + הנחיה, תוויות על המצלמה: רקע כהה שקוף + נקודת מצב, תמונות אנשים עגולות, רדיוס לפי תפקיד (משטח 12 · פקד 8 · תמונה 6 · תג עגול).

## כללים
- לא להוסיף צבע שני לפעולות. לא גרדיאנטים דקורטיביים, לא זוהר, לא אימוג'י בממשק.
- ניסוח: פועל ישיר ("גבה עכשיו"), מסך ריק = הזמנה לפעולה, שגיאה אומרת מה קרה ומה לעשות. בלי מקף ארוך כמפריד בכותרות.
- שמות הקבצים `base.css` / `components.css` / `pages.css` קבועים (רשימה לבנה ב-`backend.py`); כל קובץ קטן — נטפרי חותך כתיבות גדולות.

## בדיקה ויזואלית
`main.py --shot <תיקייה>`; צילומים עם פנים **לא** לקרוא ב-Read (נטפרי) — לשאול את `gemini_task.py -f`.
